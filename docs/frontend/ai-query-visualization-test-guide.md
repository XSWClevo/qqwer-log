## 调试技巧

### 1. 查看控制台日志

打开浏览器开发者工具（F12），查看：
```javascript
// 查看结果类型
console.log('aiQueryResultType:', aiQueryResultType.value)

// 查看 SQL
console.log('SQL:', aiQueryMetadata.value.sql)

// 查看原始结果
console.log('Result:', logs.value)
```

### 2. 检查网络请求

在 Network 标签中查看：
- 请求 URL: `/api/stats/logs/ai-query`
- 请求方法: `POST`
- 响应状态: `200`
- 响应数据结构

### 3. 检查组件状态

使用 Vue DevTools 查看：
- `aiQueryResultType` 的值
- `aiQueryMetadata` 的内容
- `logs` 数组的数据

## 常见问题排查

### Q1: 图表不显示

**可能原因**：
1. 查询结果类型为 `list`
2. 数据格式不符合预期
3. ECharts 初始化失败

**排查步骤**：
1. 检查 `aiQueryResultType` 的值
2. 查看控制台是否有 ECharts 错误
3. 验证数据结构是否正确

---

### Q2: 图标显示为方框

**可能原因**：
1. Element Plus Icons 未正确加载
2. 图标名称错误

**排查步骤**：
1. 检查网络请求是否成功加载图标库
2. 查看控制台是否有导入错误
3. 验证图标名称是否正确

---

### Q3: SQL 复制失败

**可能原因**：
1. 浏览器不支持 Clipboard API
2. 权限被拒绝

**排查步骤**：
1. 检查浏览器版本（需要现代浏览器）
2. 确认页面使用 HTTPS 或 localhost
3. 查看控制台错误信息

---

### Q4: 图表样式错乱

**可能原因**：
1. CSS 冲突
2. 暗黑模式切换问题
3. 容器大小异常

**排查步骤**：
1. 检查元素的 computed styles
2. 验证容器是否有正确的宽高
3. 尝试刷新页面
