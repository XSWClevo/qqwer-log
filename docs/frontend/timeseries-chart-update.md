### 2. ✅ 时序多维度图表

**新增组件**：`TimeSeriesChart.vue`

**功能特性**：
- 📈 折线图展示
- 📊 柱状图展示
- 📋 表格展示
- 🎨 多维度数据支持（按 facility、severity 等分组）
- 🖱️ 悬停提示显示详细信息

**数据格式支持**：
```json
[
  {
    "count": 5871,
    "time": "2025-12-31T13:00:00",
    "facility": "daemon"
  },
  {
    "count": 110,
    "time": "2025-12-31T13:00:00",
    "facility": "mail"
  }
]
```

**图表特性**：
- **X 轴**：时间（自动格式化）
- **Y 轴**：数量（自动格式化，支持 K/M 单位）
- **系列**：按维度字段（如 facility）分组
- **颜色**：自动分配 10 种颜色
- **悬停提示**：显示时间、维度名称、数值

---

### 3. ✅ 智能结果类型识别

**新增识别类型**：`timeseries`（时序统计）

**识别规则**：
```typescript
function isTimeSeriesResult(obj: any): boolean {
  const keys = Object.keys(obj)

  // 必须有时间字段
  const hasTimeField = keys.some(key =>
    /time|date|timestamp|hour|day|month/i.test(key)
  )

  // 必须有聚合字段
  const hasAggregateField = keys.some(key =>
    /count|sum|avg|max|min|total/i.test(key)
  )

  return hasTimeField && hasAggregateField
}
```

**识别优先级**：
1. 时序统计（timeseries）- 最高优先级
2. 单值统计（metric）
3. 分类统计（category）
4. 列表数据（list）

## 图表交互

### 1. 视图切换

**折线图**：
- 适合查看趋势

## 常见问题

### Q1: 图表不显示

**检查**：
1. 控制台是否显示 `识别的结果类型: timeseries`
2. 调试信息框是否显示 `显示条件: true`
3. 是否有 ECharts 错误

**解决**：
- 刷新浏览器清除缓存
- 检查数据格式是否正确

---

### Q2: 悬停提示不显示维度名称

**原因**：
- 数据中有维度字段（如 facility）
- 图表已正确识别并分组

**验证**：
- 查看图例是否显示维度值（daemon, mail, authpriv）
- 悬停时应该显示这些名称

---

### Q3: 时间格式显示不正确

**原因**：
- 时间字段格式不标准

**解决**：
- 组件会自动尝试解析常见格式
- 如果解析失败，会显示原始字符串
