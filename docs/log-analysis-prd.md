# 日志分析系统 PRD

## 1. 产品概述

### 1.1 产品定位
企业级分布式日志分析平台，提供日志的采集、解析、存储、查询、分析和可视化能力。

### 1.2 目标用户
- 运维人员：监控日志流量、排查故障
- 开发人员：追踪代码执行、调试问题
- 安全人员：分析安全事件、合规审计

### 1.3 核心价值
- **统一入口**：集中管理所有日志数据源
- **智能分析**：AI 辅助查询、自动解析、趋势预测
- **链路追踪**：全链路日志关联，快速定位问题根因
- **可视化配置**：低代码方式配置日志采集管道

## 2. 业务需求

### 2.1 用户角色与权限
| 角色 | 权限说明 |
|------|---------|
| ADMIN | 系统管理员，拥有所有权限 |
| OPERATOR | 运维人员，可管理主机、配置、告警 |
| DEVELOPER | 开发人员，可查询日志、创建提取规则 |

### 2.2 核心功能模块

#### 2.2.1 日志监控大屏 (Dashboard)
- 核心指标展示：主机状态、日志管道、存储使用率
- 实时日志流：最近 100 条日志滚动显示
- 趋势图表：日志量、错误量、分布统计
- 快捷入口：常用查询、告警列表

#### 2.2.2 日志搜索 (Log Search)
- 多数据源查询：支持单个/多个数据源联合查询
- AI 查询模式：自然语言转 SQL 查询
- 高级筛选：字段过滤、时间范围、日志级别
- 日志上下文：查看关联的前后日志
- 结果导出：支持 CSV、JSON 格式导出

#### 2.2.3 日志分析
- **趋势分析**：按时间维度统计日志量、错误率、分布
- **链路分析**：追踪请求 ID、关联请求链路、展示调用链

#### 2.2.4 告警管理
- 规则配置：基于条件、聚合、阈值配置告警
- 告警历史：查看历史告警记录、确认状态
- 通知渠道：邮件、Webhook、钉钉等

#### 2.2.5 智能助手 (Agent)
- 会话历史：保存查询对话
- 意图识别：识别用户查询意图（查询、提取、分析）
- 工具调用：自动调用查询、统计工具

#### 2.2.6 Vector 管理
- **主机管理**：管理部署 Vector 的服务器
- **配置管理**：管理 Vector 配置文件
- **组件库**：标准化 Source、Transform、Sink 组件
- **可视化配置**：流程图方式配置管道
- **安装包管理**：管理 Vector 版本包
- **日志监控**：实时查看采集日志

#### 2.2.7 数据源管理
- 多类型数据源支持：ClickHouse、Elasticsearch、PostgreSQL、MySQL、Kafka、Loki
- 连接测试：验证数据源连通性
- 配置管理：加密存储连接信息

#### 2.2.8 日志源管理
- IP 白名单：管理可信日志源 IP
- 待审核机制：新日志源需要审核后接入
- 状态管理：信任、待审核、拉黑

#### 2.2.9 智能向导 (Wizard)
- 日志解析向导：上传日志样本，自动生成提取规则
- 表结构生成：生成 ClickHouse 建表语句
- 配置模板：根据模板生成配置

#### 2.2.10 系统设置
- 用户管理：用户、角色、权限
- 数据库配置：连接信息管理
- 系统配置：各项参数配置

## 3. 非功能性需求

### 3.1 性能要求
- 日志查询响应时间 < 2 秒（100 万条数据内）
- 大屏数据刷新间隔可配置（5s/10s/30s）
- 支持并发用户数 50+

### 3.2 可用性要求
- 系统可用性 > 99.5%
- 关键功能支持故障降级（如 MCP 查询失败回退 JDBC）

### 3.3 安全要求
- 用户认证：JWT Token + Session
- 数据传输：HTTPS
- 敏感信息加密存储
- 操作审计：所有操作记录日志

### 3.4 可扩展性
- 支持动态添加数据源类型
- 支持自定义 Source/Transform/Sink 组件
- 前后端分离架构，便于扩展

## 4. 系统架构

### 4.1 技术栈
```
前端: Vue 3 + TypeScript + Element Plus + ECharts
后端: Java 21 + Spring Boot 3.2 + MyBatis Plus
数据: PostgreSQL (元数据) + ClickHouse (日志数据)
缓存: Redis
队列: 无 (同步处理)
向量: LangChain4j (AI 能力)
```
