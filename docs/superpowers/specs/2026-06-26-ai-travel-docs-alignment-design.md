# AI游宜昌申报材料统一口径设计说明

## 目标

统一申报书与计划书的核心口径，保证两份材料在项目名称、团队身份、项目阶段和落地表述上保持一致，同时不改动用户的真实基础信息。

## 已确认方案

- 保留申报书中的项目所在地为 `湖北省武汉市江夏区`
- 保留项目聚焦宜昌新文旅场景的方向
- 对计划书中的表述做适度收敛，统一为“以宜昌为重点示范场景”
- 将项目标准名称统一为 `AI游宜昌——面向新文旅场景的城市智能导览与内容生成平台`
- 两份材料统一为 `个人参赛、1人团队、创新/原型阶段`

## 调整范围

### 申报书

- 统一参赛项目名称
- 保持个人信息、所在地、联系电话等真实信息不变
- 不虚构团队名称、公司主体或注册信息
- 保持“未注册公司”“创新阶段”等现有状态一致

### 计划书

- 保留现有整体结构和大部分正文
- 将容易被理解为“项目已在宜昌本地落地”的表述，调整为“以宜昌为重点示范场景”或“围绕宜昌重点场景开展验证”
- 继续保持单人团队、原型阶段和审慎商业化表述

## 成功标准

- 两份文档中的项目名称一致
- 两份文档不再出现“项目所在地在武汉，但文案像已在宜昌正式落地”的明显冲突
- 团队身份、项目阶段、项目定位保持一致
- 修改后重新渲染检查，确保版式正常
